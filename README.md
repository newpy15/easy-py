> **하늘에서 떨어지는 파이썬 코드를 정확히 타이핑해서 받아치세요!**
> 60초 동안 얼마나 많은 코드를 입력할 수 있는지 도전해보세요.

## 🎮 바로 플레이하기

### 👉 [**게임 시작하기 (클릭!)**](https://newpy15.github.io/easy-py/)

설치 없이 브라우저에서 바로 실행됩니다.

## ✨ 이런 게임이에요

- ⌨️ **떨어지는 코드를 타이핑**해서 Enter로 받아치기
- ⏱ **60초** 제한 시간
- ❤️ 목숨 3개 (블록을 놓치면 감소)
- 📚 **모르는 함수에 마우스를 올리면 설명**이 나와요
- 🎯 **난이도 3단계** (쉬움 / 보통 / 어려움)
- ⚡ 게임 중에도 **방향키로 속도·단어 빈도 실시간 조절**
- 📊 게임 종료 후 **놓친 코드를 복습**할 수 있어요

## 🕹️ 조작법

| 키 | 기능 |
|----|------|
| **타이핑** | 블록의 코드 입력 |
| **Enter** | 입력한 코드와 일치하는 블록 제거 |
| **Backspace** | 입력 지우기 |
| **↑ / ↓** | 낙하 속도 조절 (1~5) |
| **← / →** | 단어 빈도 조절 (1~5) |

## 🎯 난이도

| 단계 | 내용 | 예시 |
|------|------|------|
| 🟢 **Lv.1 쉬움** | 짧은 기본 함수/연산 | `len(x)`, `abs(-3)` |
| 🟡 **Lv.2 보통** | 긴 문법/함수 조합 | `range(10)`, `def f():` |
| 🟣 **Lv.3 어려움** | 문자열 리터럴 포함 | `print('train')`, `int('42')` |

> Lv.3은 **따옴표 안 영어 단어까지 정확히** 입력해야 해요. 실전 코딩 감각을 길러보세요!

## ⚡ 실시간 설정

게임을 시작하기 전이나 플레이 중에도 **방향키로 난이도를 즉시 조절**할 수 있어요.

| 설정 | 조절 키 | 단계 |
|------|---------|------|
| **낙하 속도** | `↑` 빠르게 / `↓` 느리게 | 1 (매우 느림) ~ 5 (매우 빠름) |
| **단어 빈도** | `→` 많이 / `←` 적게 | 1 (3초마다) ~ 5 (0.7초마다) |

우측 패널에서 현재 설정을 항상 확인할 수 있습니다.

## 🧠 이런 걸 배울 수 있어요

- 파이썬의 **기본 함수** (`len`, `abs`, `sum`, `max` …)
- **연산자** (`**`, `%`, `+=` …)
- **문법 키워드** (`def`, `return`, `if`, `while`, `import`, `lambda` …)
- **문자열 리터럴**과 따옴표 표기
- 영어 단어를 정확하고 빠르게 입력하는 **타이핑 감각**
